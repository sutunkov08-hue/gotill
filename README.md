# GORILLA RUSH 🦍

Браузерная пародия на **Gorilla Tag**: низкополигональная арена, горилла без ног и передвижение
только отталкиванием руками. Один HTML-файл — работает по двойному клику и на GitHub Pages.

## Запуск

- **Локально:** откройте `index.html` двойным кликом (нужен интернет — Three.js грузится с CDN).
- **GitHub Pages:** Settings → Pages → deploy from branch `main` (`/root`). Игра откроется по адресу `https://<user>.github.io/gotill/`.

## Управление

| Ввод | Действие |
|---|---|
| **Мышь** | вращение камеры (вид от первого лица) |
| **Q** (зажать) | мышь управляет левой рукой, камера замирает |
| **E** (зажать) | мышь управляет правой рукой, камера замирает |
| ЛКМ по кнопке | старт / продолжить (захват мыши) |

**Как двигаться:** поставь ладонь на пол (курсор на землю) и резко отведи мышь в сторону —
тело получит импульс в противоположную сторону. Чем резче рывок, тем сильнее толчок.
Чтобы залезть на дерево или платформу: цепляй ладонь выше и тяни прицел вниз — тело подтянется вверх.

## Геймплей

- Арена 50×50: платформы, стены и деревья, по которым можно лазать.
- Режим «догонялки»: заражённый горилла-бот охотится на тебя и двух ИИ-выживших.
  Поймаешь всех (или тебя поймают) — конец раунда; таймер раунда — 2 минуты.
- Счёт: время выживания и число заражённых. Кнопка рестарта на экране итогов.

## Техника

- Three.js (CDN, importmap), физика написана с нуля: тело + две «ладони»-частицы.
- Ладонь при контакте «прилипает» к поверхности; движение мышью при упоре передаётся
  телу как реакция опоры (с усилением на подтягивание вверх). Резкость мыши = сила толчка.
- Бот ходит той же физикой: цикл «посадил ладонь → оттолкнулся», у заражённого есть рывок ярости вблизи жертвы.
- Звук синтезируется WebAudio (шлепки, поимка, итоги) — без внешних файлов.
- 60 FPS, ресайз окна, вид от первого лица (голова скрыта, тело и ладони видны), pointer lock.

## Проверка физики

Headless-смоук-тесты (Node + заглушки рендера) покрывают: покой на полу, бег на руках,
подтягивание при лазании, гравитацию, импульс от шлепка, стены арены, вис на зацепе,
догоняющий ИИ и конечность всех координат.
